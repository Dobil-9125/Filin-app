# FILIN 앱 시제품

FILIN(필린) 고객용 앱의 첫 시제품이에요. 휴대폰 화면에 맞춘 웹페이지 한 장으로 만들었어요.

## 들어 있는 기능

- **홈**: 필린 소개, 우리 아이에게 먼저 권하는 사료, 인기 제품
- **맞춤 추천**: 강아지/고양이, 나이, 체중, 활동량, 고민을 고르면 사료 3가지를 이유와 함께 추천
- **제품**: 토우·퓨어비타·뉴트리소스·벨포아 23가지 제품을 브랜드·동물별로 보기
- **급여량**: 하루 급여량, 한 봉지가 며칠 가는지, 다시 주문할 날짜 계산
- **샘플·내 아이**: 첫 구매 샘플 키트 신청(3가지까지), 아이 정보

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 앱 전체 (화면 디자인, 제품 데이터, 추천 규칙이 모두 이 파일 안에 있어요) |
| `img/` | 제품 사진과 올리·세리 그림 |

`index.html` 안에서 자주 고칠 곳은 다음과 같아요.

- 제품을 더하거나 고치기: `const P = [` 로 시작하는 목록
- 추천 규칙 바꾸기: `function recommend(` 부분
- 급여량 계산식 바꾸기: `function feeding(` 부분
- 색 바꾸기: 맨 위 `:root{` 안의 `--slate`, `--amber` 같은 값

## 내 컴퓨터에서 열어 보기

`index.html` 파일을 크롬이나 사파리로 열면 바로 보여요. 설치할 것은 없어요.

## 아직 시제품인 부분

- 구매 버튼과 샘플 신청은 실제로 처리되지 않아요. 네이버 브랜드스토어 링크를 아직 연결하지 않았어요.
- 열량은 토우 퍼시픽 스트림(3,600kcal/kg)만 확인된 값이고, 나머지 제품은 화면에서 직접 넣도록 기본값을 두었어요.
- 수불부에 용량이 없는 제품은 예시 봉지 용량을 썼어요.
- 아이 정보와 샘플 선택은 그 브라우저에만 저장돼요.
