# FILIN 앱 시제품

FILIN(필린) 고객용 앱의 첫 시제품이에요. 휴대폰 화면에 맞춘 웹페이지 한 장으로 만들었어요.

## 들어 있는 기능

- **홈**: 올리·세리 인사, 다음 정기배송 안내, 우리 아이에게 먼저 권하는 사료, 브랜드관, 인기 제품
- **맞춤 추천**: 세리가 질문 3개(찾는 밥, 피할 재료, 활동량)를 하고 올리가 사료 3가지를 추천. 답은 아이 프로필에 저장
- **제품**: 토우·퓨어비타·뉴트리소스·벨포아 24가지 제품을 브랜드별로 나눠 보여요. 개밥왕 스마트스토어 기준 용량별 가격(`PRICE`), 원료, 열량. 정기배송은 7% 할인가로 보여요. 상세 화면에서 한 번 구매 / 정기배송(7% 할인) 선택, 급여량으로 배송 주기 추천
- **주문·배송**: 정기배송 목록(주기 변경·건너뛰기·지금 받기·해지), 내 주문(배송 조회·다시 주문·후기 쓰기), 급여량으로 주기 정하기
- **건강 체크**: 식욕·기운·변·구토·물을 매일 기록, 최근 7일 보기, 살펴봐야 할 신호면 상담 안내, 블로그 정보 글 요약
- **수의사 상담**: 채팅/영상, 고민 분야, 희망 시간, 프로필·건강 기록 함께 보내기 (응급 안내 포함)
- **제품 후기·Q&A**: 제품 상세의 후기 탭(별점·후기 쓰기, 예시 후기는 '예시'로 표시)과 Q&A 탭(자주 묻는 질문·질문 남기기)
- **내 아이**: 여러 마리 등록, 아이 사진(정사각형으로 줄여 프로필에 저장), 생일·품종·체중·중성화·알러지·약/지병, 생일 달 안내, 첫 구매 샘플 키트

정기배송, 프로필, 주문 조회, 수의사 상담(Connect with a Vet), 건강 기록, 후기·Q&A는 미국 Chewy 앱을 참고했어요. 홈 화면 아이콘은 기획안의 FILIN 올리·세리 로고예요.

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 앱 전체 (화면 디자인, 제품 데이터, 추천 규칙이 모두 이 파일 안에 있어요) |
| `img/` | 제품 사진과 올리·세리 그림 |
| `vendor/` | 로그인·데이터베이스 연결에 쓰는 Supabase 라이브러리 (버전 고정) |
| `supabase/setup.sql` | 데이터베이스 표와 잠금장치(RLS)를 만드는 SQL. Supabase SQL Editor에서 한 번 실행 |

`index.html` 안에서 자주 고칠 곳은 다음과 같아요.

- 제품을 더하거나 고치기: `const P = [` 로 시작하는 목록
- 추천 규칙 바꾸기: `function recommend(` 부분
- 세리 질문 바꾸기: `const QUESTIONS = [` 부분
- 알러지·품종 목록: `const ALLERGENS`, `const BREEDS`
- 급여량 계산식 바꾸기: `function feeding(` 부분
- 색 바꾸기: 맨 위 `:root{` 안의 `--slate`, `--amber` 같은 값

## 내 컴퓨터에서 열어 보기

- `filin-app-onefile.html`: 사진까지 파일 하나에 다 들어 있어요. 이 파일만 받아서 크롬이나 사파리로 열면 사진이 깨지지 않고 보여요. 카톡이나 메일로 보내기에도 이 파일이 편해요.
- `index.html`: 고쳐 쓰는 원본이에요. `img/` 폴더와 같은 곳에 있어야 사진이 보여요. 저장소 전체를 받거나(Code → Download ZIP) GitHub Pages로 열면 돼요.

`index.html`을 고친 뒤에는 `filin-app-onefile.html`도 다시 만들어야 같은 화면이 돼요. (첫 화면 사진은 통합 브랜드관 기획안 PDF에서 뽑은 올리·세리와 브랜드 이미지예요.)

## 회원가입·로그인 (Supabase)

- 프로젝트 주소와 공개 키(publishable)는 `index.html`의 `SUPABASE_URL`, `SUPABASE_KEY`에 있어요. 공개 키는 앱에 넣어도 되는 키예요. secret/service_role 키는 절대 넣지 마세요.
- 처음 한 번: Supabase → **SQL Editor**에서 `supabase/setup.sql` 전체를 실행
- Supabase → **Authentication → URL Configuration**에서 Site URL을 `https://dobil-9125.github.io/Filin-app/`로 저장 (인증·비밀번호 재설정 메일 링크가 앱으로 돌아오게)
- 회원 데이터는 `user_data` 표에 회원 한 명당 한 줄(JSON)로 저장되고, 본인만 읽고 쓸 수 있어요.
- 가입할 때 휴대폰 번호를 받아 Supabase 회원 정보(user_metadata의 `phone`, 숫자만)에 저장해요. 나중에 네이버 커머스API로 가져온 주문의 **주문자 번호**와 맞춰 앱 주문·배송에 연결하는 데 써요. 지금은 문자 인증 없이 저장만 하고 `phone_verified`는 false예요. 출시 전에 문자 인증(또는 네이버 로그인)을 붙여야 해요.

## 휴대폰에 앱으로 설치하기

1. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 두고 **Save**
2. 1~2분 뒤 휴대폰에서 https://dobil-9125.github.io/filin-app/ 열기
3. 아이폰(사파리): 공유 버튼 → **홈 화면에 추가** / 갤럭시(크롬): ⋮ → **앱 설치** 또는 **홈 화면에 추가**

설치에 쓰이는 파일:

| 파일 | 하는 일 |
| --- | --- |
| `manifest.webmanifest` | 앱 이름(필린), 아이콘, 전체 화면으로 열기 설정 |
| `icons/` | 홈 화면 아이콘 |
| `sw.js` | 화면과 사진을 휴대폰에 저장해 인터넷 없이도 열리게 함. `index.html`이나 사진을 바꾸면 `VERSION` 숫자를 올려 주세요 |

## 아직 시제품인 부분

- 주문, 샘플 신청, 정기배송, 수의사 상담, 후기·질문은 실제로 처리·전달되지 않아요. 예시 주문·예시 후기·예시 건강 기록은 화면 확인용이에요. 네이버 브랜드스토어 링크를 아직 연결하지 않았어요.
- 열량은 스마트스토어·개밥왕 상세페이지 값이에요. 컵당 kcal만 있는 제품은 컵 무게로 나눠 kcal/kg로 바꿨어요. 퓨어비타 캣 2종·칠면조&고구마는 아직 열량이 없어서 화면에서 직접 넣는 기본값을 써요.
- 각 제품의 `also`에는 주 단백질 말고 들어 있는 알러지 원료(예: 닭 분말, 연어오일)를 적어 두었고, 추천 주의 문구와 FAQ가 이걸 써요.
- 수불부에 용량이 없는 제품은 예시 봉지 용량을 썼어요.
- 로그인하지 않으면 아이 정보, 샘플, 정기배송은 그 휴대폰(브라우저)에만 저장돼요. 홈 화면 앱과 사파리/크롬도 서로 따로 저장돼요. 로그인하면 Supabase 계정에 저장돼 다른 기기에서도 이어 볼 수 있어요. 앱으로 돌아오거나 화면을 아래로 당기면 계정의 최신 정보를 다시 불러와요.
- 회원 탈퇴(계정 삭제)와 개인정보 처리방침은 출시 전에 따로 만들어야 해요. 가입 화면의 동의 문구는 시제품용이에요.
